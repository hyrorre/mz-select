mnpy氏により作成された m-select をベースに、bmz-player 向けの拡張を加えたスキンです。

選曲画面のBMZ拡張:
・E2 holdでDETAIL OPTIONSを表示します。項目は横7列、選択肢は各列に縦並びです。
  中央の項目を明るい列枠、現在値を旧パネルの発光カーソルで示します。三角・丸のマーカーは使いません。
・スクラッチ／左右で項目選択、奇数鍵／下で次の値、偶数鍵／上で前の値へ変更します。
  見出し・選択肢はマウスでも操作できます。E2を離すと閉じます。
・元のAssistパネルと同じ300msのアニメーションで左から表示します。選曲画面が透ける背景です。
  E2を離すと300msで左へ戻って閉じます。E2とE1+E2の切り替えでは退出と登場を同時に再生します。
  退出中のE2は編集できず、切り替え先のパネルを操作します。パネルなしへ閉じる間は背後へのクリックを遮断します。
  ボタン等は元の画像を再利用し、焼き込み文字を黒で覆って現在の値を描画します。
  選択肢の英数字はバージョン・IR表示と同じフォントです。括弧だけ既存の別atlasから補っています。
  表示は項目一覧と説明・補助情報に絞り、タイトルや操作ガイドは付けていません。
・項目は循環し、選曲と同じ時間設定で中央へスクロールします。
  保存量・GAS方式・非適用理由は本体から受け取って表示します。
・default_detailoptions/parts.luaをenable.txtで有効にしています。
  この部品を無効にした場合、BMZでも元のAssist表示とKEY1〜7の固定操作に戻ります。
  beatorajaでは元のAssistパネルを維持します。E1とE1+E2は従来通りです。
この拡張にはDETAIL OPTIONS v1、選択肢セル、bmzDetailScroll、bmzDetailOptionsCloseに対応したBMZ Playerが必要です。

antiqueのBMZ拡張:
・「Ambient」: 既定OFF。ONでBGA/汎用背景をぼかして画面の背面に表示します。
・「Ambient表示方式」: 全体（既定）／Spread。
・「Spread範囲 (%)」: 0～200%、10%刻み、既定20%。実際の映像範囲の幅・高さを拡大します。
  20%なら幅・高さが1.2倍。映像外周はぼかして透明へ減衰します。
・「Ambientぼかし度 (%)」: 0～100%、10%刻み、既定50%。0%ではぼかしません。
・「Ambientパネル透明度」: ON時のパネル透明度を0～100%の10%刻みで設定できます（既定40%）。
  レーン背景は対象外で、不透明度100%を維持します。
  数値・テキスト・ノーツ・判定・グラフ本体の透明度は変わりません。
  フレーム画像に含まれる装飾やラベルはフレームと一緒に透過します。
・ON時は従来の暗いBGA背景を省き、鮮明なBGAとAmbientを表示します。
  BGAサイズが「背景(1920x1080)」の場合は選択した全体／SpreadのAmbientだけを表示します。
この演出にはambient / ambientMode / ambientSpread / ambientBlurに対応したBMZ Playerが必要です。
・「前面BGAの明るさ(-255 ~ 0)」: 前面の映像部分だけの明るさを調整します。旧BGA明るさの設定値を引き継ぎます。
・「背景/Ambient BGAの明るさ(-255 ~ 0)」: 通常の背景BGAと全体／Spread Ambientの明るさを調整します。
  どちらも既定0（元の明るさ）、-255で黒。前面を暗くしても背景は透けません。
  BGAサイズが「背景(1920x1080)」の場合は背景側の設定を使います。
