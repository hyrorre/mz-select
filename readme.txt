mnpy氏により作成された m-select をベースに、bmz-player 向けの拡張を加えたスキンです。

BMZのG-BATTLE一覧では、左下に相手のオプションと鍵盤配置を表示します。
一覧を閉じるとランキング / rival data / ir dataへ戻ります。
情報がない相手や固定配置のないオプションは未取得 / 固定配置なしと表示します。
HARD等のゲージ名は表示しません。既存のフォントとリザルト鍵盤素材を使用しています。
背景は半透明の黒地と左の白線、英字と鍵盤番号はNETWORK / score dataと同じ字体です。
NO DATA（未取得）/ LOADING（読み込み中）/ NOT FIXED（可変配置）を区別します。
